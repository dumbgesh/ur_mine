## Linear regression is used to predict a numerical value based on the relationship between variables.

For example, a college might predict a student's exam marks based on study hours.

The basic equation is:
\[
y = mx + c
\]

- \(y\) = predicted value (marks)
- \(x\) = input value (study hours)
- \(m\) = slope
- \(c\) = intercept
